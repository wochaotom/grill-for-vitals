# Vault Research

Load this only when the user asks for vault research or the local context clearly depends on the user's own Obsidian vault doctrine. Most Grill runs never need it.

Follow the relevant vault skill's rules exactly:

- Academic: use `aquery` and the Academic retrieval rules. By default, do not consult Academic Graphify. If the user explicitly changes that policy in the current turn, use Academic Graphify only as a navigation map to find candidate notes or terms, never as evidence or coverage.
- Business: use `bquery` and the Business retrieval rules. Business Graphify is retired; use `QUERY-ENTRY.md` and query packs only as routing hints, then verify against deterministic retrieval receipts and durable notes read directly in this run.
- Any overflowed retrieval is navigation only unless the full candidate set is read through the required process.

Before making vault-grounded claims, apply `anti-overexpansion-query-protocol.md`.
